# SSAT Elementary Verbal Prep App

An interactive, timed SSAT Verbal practice application covering all 50 Elementary Level vocabulary words with:
- **Full 50-Word Master Examination**
- **Official 30-Question SSAT Simulations (Module A & Module B)**
- **Real 20-minute and 35-minute countdown timers**
- **Instant automated grading, scaled score estimates & percentile rank**
- **Detailed answer explanations and analogy bridges**
- **Interactive 50-Word Flashcard deck**

## Live Test via GitHub Pages
This repository is self-contained and ready to run on GitHub Pages with zero build step.
